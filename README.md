# TranquiliCare

Plataforma que aproxima pessoas de organizações e causas, tornando doações,
histórias de impacto e acompanhamento mais humanos e transparentes.

## Desenvolvimento

- Instale as dependências com `npm install`.
- Inicie o ambiente local com `npm run dev`.

## Verificações

- Testes: `npm test -- --run`
- Lint: `npm run lint`
- Build: `npm run build`

## Tecnologias

- React
- TypeScript
- Vite
- Tailwind CSS
- Supabase
- Framer Motion
